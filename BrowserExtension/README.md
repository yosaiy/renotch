# Re:notch Browser Activity

This unpacked Chromium extension sends YouTube playback metadata and browser download progress to the bundled Re:notch native messaging bridge.

## Install for development

1. Build and launch `dist/Re:notch.app` with `./scripts/build-app.sh`.
2. Choose **Set Up Browser Activity…** from the Re:notch menu-bar menu. This registers the bundled native messaging host and reveals this directory.
3. Open `chrome://extensions` (or the equivalent page in Edge or Brave).
4. Enable **Developer mode**, choose **Load unpacked**, and select the revealed `BrowserExtension` directory.

After updating the source, click **Reload** on the extension card. Existing YouTube tabs are reinjected automatically, so Brave does not require a page reload.

The extension ID is pinned to `lekadelliioeecihidklkhmbmmadcklh`, matching the native-host allowlist generated by the app.

## Permissions

- `youtube.com`: reads playback state, title, channel, position, duration, and video ID.
- `downloads`: reads active browser download filenames, states, and byte progress.
- `nativeMessaging`: sends those local activity events to Re:notch.

No browsing history or activity from other websites is collected or stored.
